## 项目目标

以多元宇宙与未来世界观为起点，将参数化几何、粒子交互和生成式影像连接为一条连续的创作路径。通过生物形态与机械结构的组合，构建一个由不同时间线相互支撑、不断生长和变化的混合生态空间。

## 我的贡献

参数化建模、交互编程与生成影像设计

完成阶段：概念模型、粒子交互与生成影像

现有产出：参数化分析、Rhino 模型、Processing 粒子交互、ComfyUI 工作流与动态影像

## AI 与制作工作流

### 1. 参数化形态

Rhino 与 Grasshopper 构建概念几何、形态关系与参数化空间。

### 2. 实时粒子交互

Processing 将几何转为点云、粒子、藤蔓与烟花反馈，网页保留源模型导出的几何和点云展示。

### 3. ComfyUI 生成影像

以参数化视觉为输入建立生成式图像与视频工作流，让同一形态在不同时间线中延展。

### 4. 人工视觉控制

调整构图、颜色、形态连续性与动态节奏，筛选能保持世界观的一组输出。

### 5. 证据

仓库保留工作流截图、分析图、交互录屏、模型数据和成片；当前材料中的 ComfyUI 工作流以图像记录展示。
